KEEPING THE ARCHIVE

Wiki editor & publishing

How publication works

Editing works locally, even before you publish. To make changes visible to everyone, use a GitHub fine-grained personal access token restricted to this wiki repository with Contents: Read and write. The token is kept only in memory while this page is open — never in wiki files or browser storage.

Keep the token private. Other players can read the wiki without one. A token holder can update the public content.

Create a restricted token ↗

Never paste your token into a wiki article, screenshot, issue, or chat. Publishing checks for remote edits and stops instead of silently overwriting someone else's work.
